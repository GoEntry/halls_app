# 🚀 Быстрый старт - HALLS

## Запуск за 3 шага

### 1️⃣ Установка зависимостей
```bash
cd frontend
npm install
```

### 2️⃣ Запуск dev-сервера
```bash
npm start
```

### 3️⃣ Открыть в браузере
```
http://localhost:5173
```

## 🎯 Что попробовать

### Навигация
1. Откройте приложение
2. Наведите курсор на ссылки в header
3. Посмотрите как плавно перемещается зеленое выделение
4. Кликните на разные разделы
5. Обратите внимание на плавные переходы между страницами

### Тренировки
1. Перейдите в "Тренировки"
2. Нажмите "Добавить тренировку"
3. Заполните форму
4. Посмотрите автоматический расчет калорий
5. Используйте поиск и фильтры

### Питание
1. Перейдите в "Питание"
2. Добавьте прием пищи
3. Посмотрите прогресс-бар дневной цели
4. Попробуйте готовые планы питания

### Цели
1. Перейдите в "Цели"
2. Создайте новую цель
3. Обновите прогресс
4. Посмотрите визуальные индикаторы

### Профиль
1. Перейдите в "Профиль"
2. Заполните информацию
3. Посмотрите автоматический расчет ИМТ
4. Проверьте статистику

## 📱 Тестирование адаптивности

### Desktop
- Откройте в полноэкранном режиме
- Все блоки выровнены и центрированы

### Tablet
- Измените размер окна до 768px
- Блоки перестраиваются в одну колонку

### Mobile
- Откройте DevTools (F12)
- Выберите мобильное устройство
- Навигация адаптируется

## 🎨 Проверка анимаций

### Переходы страниц
- Переключайтесь между разделами
- Контент плавно исчезает и появляется
- Нет резких скачков

### Навигация
- Наведите курсор на ссылки
- Зеленое выделение плавно перемещается
- При клике - плавный переход к новой ссылке

### Hover эффекты
- Наведите на карточки - они поднимаются
- Наведите на кнопки - меняется цвет
- Наведите на логотип - увеличивается

## 📂 Структура данных

Все данные хранятся в localStorage:

```javascript
// Тренировки
localStorage.getItem('trainingLog')

// Питание
localStorage.getItem('meals')

// Цели
localStorage.getItem('goals')

// Профиль
localStorage.getItem('userProfile')

// Цель по весу
localStorage.getItem('weightGoal')
```

### Очистка данных
Откройте DevTools → Application → Local Storage → Удалите нужные ключи

## 🐛 Возможные проблемы

### Порт занят
```bash
# Измените порт в vite.config.js
server: {
  port: 3000
}
```

### Шрифты не загружаются
- Проверьте путь в `src/fonts/fonts.css`
- Убедитесь что файлы `.woff` на месте

### Анимации не работают
- Очистите кэш браузера (Ctrl+Shift+R)
- Проверьте консоль на ошибки
