### 3. CSS переменные для тем ✅

**Светлая тема:**
```css
--bg-primary: linear-gradient(118deg, #87e0cb, #c6e088)
--text-primary: #000
--header-bg: rgba(255, 255, 255, 0.95)
--bg-card: rgba(255, 255, 255, 0.95)
```

**Темная тема:**
```css
--bg-primary: linear-gradient(118deg, #1a4d44, #3d5a2e)
--text-primary: #fff
--header-bg: rgba(30, 30, 30, 0.95)
--bg-card: rgba(40, 40, 40, 0.95)
```

### 4. Композабл useTheme ✅

```javascript
import { useTheme } from '@/composables/useTheme';

const { theme, toggleTheme } = useTheme();
```

**Функции:**
- `theme` - текущая тема (ref)
- `toggleTheme()` - переключение темы
- `setTheme(newTheme)` - установка конкретной темы
- `isDark()` - проверка темной темы

### 5. Плавные переходы ✅
- Все элементы плавно меняют цвет при переключении темы
- Transition: 0.3s ease для всех свойств
- Градиенты адаптируются под тему

## Как использовать:

1. **Откройте приложение**
2. **Найдите кнопку** с иконкой луны/солнца в header (справа)
3. **Кликните** для переключения темы
4. **Тема сохраняется** и применяется при следующем визите

## Технические детали:

**Файлы:**


**Применение:**
```javascript
document.documentElement.setAttribute('data-theme', 'dark')
```

## Что исправлено:

### Проблема 1: Прыжок при наведении ❌ → ✅
**Было:**
```css
&:hover {
  transform: translateY(-1px); // Вызывало прыжок
}
```

**Стало:**
```css
&:hover {
  color: var(--text-primary); // Только цвет
}
```

### Проблема 2: Белый текст сливается ❌ → ✅
**Было:**
```css
&.router-link-active {
  color: #fff; // Плохо видно
}
```

**Стало:**
```css
&.router-link-active {
  color: #fff;
  text-shadow: 0 1px 2px rgba(0, 0, 0, 0.2); // Тень для читаемости
}
```
