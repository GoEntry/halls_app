# Анимации в HALLS

## Реализованные анимации

### 1. Переходы между страницами

**Эффект:** Плавное появление и исчезновение контента при смене страниц

**Технические детали:**
- Используется Vue Transition с режимом `out-in`
- Длительность: 300ms
- Easing: ease

**Поведение:**
- При уходе со страницы: контент плавно исчезает и смещается вверх
- При входе на страницу: контент плавно появляется и смещается снизу вверх

```vue
<Transition name="page" mode="out-in">
  <component :is="Component" />
</Transition>
```

**CSS:**
```css
.page-enter-from {
  opacity: 0;
  transform: translateY(20px);
}

.page-leave-to {
  opacity: 0;
  transform: translateY(-20px);
}
```

### 2. Анимация навигации

**Эффект:** Плавно перемещающееся зеленое выделение за активной ссылкой

**Технические детали:**
- Динамический фоновый элемент с абсолютным позиционированием
- Transition: 400ms cubic-bezier(0.4, 0, 0.2, 1)
- Градиентный фон: linear-gradient(135deg, #87e0cb, #c6e088)
- Тень: box-shadow для глубины

**Поведение:**
- При загрузке страницы: выделение автоматически позиционируется под активной ссылкой
- При наведении: выделение плавно перемещается под курсор
- При уходе курсора: выделение возвращается к активной ссылке
- При смене страницы: выделение плавно перемещается к новой активной ссылке

**Реализация:**
```javascript
const updateNavBg = (index) => {
  const link = linkRefs.value[index];
  const rect = link.getBoundingClientRect();
  
  navBgStyle.value = {
    left: `${rect.left - navRect.left}px`,
    width: `${rect.width}px`,
    opacity: '1'
  };
};
```

### 3. Дополнительные анимации

**Hover эффекты:**
- Логотип: scale(1.05) при наведении
- Ссылки навигации: translateY(-1px) при наведении
- Карточки: translateY(-10px) при наведении

**Transitions:**
- Все интерактивные элементы имеют плавные переходы
- Длительность: 200-400ms
- Различные easing функции для естественности

## Производительность

**Оптимизации:**
- Использование CSS transforms вместо position для анимаций
- GPU-ускорение через transform и opacity
- Debounce для resize событий
- Минимальное количество reflow/repaint

**Размер bundle:**
- CSS: 63.64 kB (gzip: 8.68 kB)
- JS: 147.72 kB (gzip: 51.68 kB)
- Время сборки: ~440ms

## Адаптивность

Все анимации корректно работают на:
- Десктопах (плавные переходы)
- Планшетах (адаптированные размеры)
- Мобильных устройствах (оптимизированные анимации)

## Кастомизация

Для изменения анимаций отредактируйте:

**Переходы страниц:** `src/App.vue`
```css
.page-enter-active,
.page-leave-active {
  transition: opacity 0.3s ease, transform 0.3s ease;
}
```

**Навигация:** `src/components/layout/AppHeader.vue`
```css
&__nav-bg {
  transition: all 0.4s cubic-bezier(0.4, 0, 0.2, 1);
}
```
