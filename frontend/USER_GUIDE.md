# HALLS - Полное руководство по приложению

## Обзор

HALLS - это современное веб-приложение для отслеживания тренировок, контроля питания и достижения фитнес-целей. Приложение построено на Vue.js 3 с использованием Composition API и предоставляет полноценный функционал для управления здоровым образом жизни.

## Основные возможности

### 1. Главная страница (Dashboard)
- Быстрый доступ ко всем разделам
- Карточка следующей тренировки
- Отображение цели по весу
- Статистика последней тренировки
- Быстрые действия: добавить тренировку, журнал тренировок

### 2. Журнал тренировок
**Функции:**
- Просмотр всех тренировок в виде карточек
- Поиск по типу тренировки
- Фильтрация по категориям (Бег, Велосипед, Плавание, Йога, Силовая)
- Статистика: общее количество, дистанция, калории
- Удаление тренировок
- Редактирование существующих записей

**Добавление тренировки:**
- Выбор типа из предустановленного списка
- Указание даты и длительности
- Расстояние и средний пульс
- Автоматический расчет калорий
- Заметки о тренировке

### 3. Журнал питания
**Возможности:**
- Отслеживание приемов пищи за день
- Подсчет калорий, белков, жиров, углеводов
- Визуальный прогресс-бар дневной цели
- Добавление приемов пищи с полной информацией
- Готовые планы питания (2000, 3000, 4000 ккал)

**Добавление приема пищи:**
- Название (Завтрак, Обед, Ужин и т.д.)
- Время приема
- Калории и макронутриенты
- Описание блюд

### 4. Видео-тренировки
**Каталог включает:**
- 8 готовых видео-тренировок с YouTube
- Категории: Домашние, Кардио, Силовые, Йога, HIIT
- Информация о длительности и уровне сложности
- Превью видео
- Прямые ссылки на YouTube

### 5. Цели и прогресс
**Управление целями:**
- Создание персональных целей
- Отслеживание прогресса с визуальным индикатором
- Различные единицы измерения (кг, км, раз, мин, ккал)
- Установка сроков достижения
- Статусы: В процессе, Достигнута, Просрочена, Срочная
- История достигнутых целей

### 6. Профиль пользователя
**Личная информация:**
- Имя, фамилия, email, телефон
- Дата рождения и пол
- Аватар пользователя

**Физические параметры:**
- Рост и вес
- Автоматический расчет ИМТ (индекс массы тела)
- Категория веса (недостаточный, нормальный, избыточный)

**Цели и предпочтения:**
- Основная цель (снижение веса, набор массы, поддержание формы и т.д.)
- Уровень активности
- Предпочитаемые виды тренировок

**Статистика:**
- Всего тренировок
- Дней с нами
- Сожжено калорий
- Активных целей

## Технические детали

### Стек технологий
- **Frontend:** Vue.js 3 (Composition API)
- **Роутинг:** Vue Router 4
- **Стили:** SCSS с модульной архитектурой
- **Шрифты:** Brotesk, Sonic Italic
- **Анимации:** AOS (Animate On Scroll)
- **Хранение:** localStorage (временно, до подключения backend)

### Структура маршрутов
```
/ - Главная страница
/trainings - Журнал тренировок
/trainings/new - Добавление тренировки
/trainings/:id - Редактирование тренировки
/nutrition - Журнал питания
/videos - Видео-тренировки
/goals - Цели и прогресс
/profile - Профиль пользователя
```

### Хранение данных
Все данные сохраняются в localStorage:
- `trainingLog` - журнал тренировок
- `meals` - приемы пищи
- `goals` - цели пользователя
- `userProfile` - профиль пользователя
- `weightGoal` - цель по весу

## Адаптивность

Приложение полностью адаптивно и корректно работает на:
- Десктопах (1920px+)
- Ноутбуках (1200px - 1920px)
- Планшетах (768px - 1200px)
- Мобильных устройствах (320px - 768px)

## Запуск приложения

### Разработка
```bash
cd frontend
npm install
npm start
```
Приложение будет доступно по адресу: http://localhost:5173

### Продакшн
```bash
npm run build
```
Результат сборки будет в папке `dist/`
