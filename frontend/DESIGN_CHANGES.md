# Изменения в дизайне

## Выравнивание блоков

### Что было исправлено:

1. **Выравнивание по высоте**
   - Все блоки в колонках теперь выровнены по одной линии
   - Используется `align-items: stretch` для растягивания блоков
   - Добавлен `height: 100%` для всех карточек
   - Правая колонка с действиями (`__actions`) использует `align-self: stretch`

2. **Увеличение размеров блоков**
   - Ширина колонок: 306px → 380px
   - Ширина панели действий: 108px → 140px
   - Максимальная ширина layout: 1400px → 1600px
   - Увеличены отступы между блоками: 16px → 20px

3. **Увеличение контента**
   - Шрифты заголовков: 25px → 28px
   - Шрифты больших чисел: 80px → 90px
   - Шрифты акцентных блоков: 32px → 36px
   - Иконки действий: 75px → 90px
   - Иконка добавления тренировки: 100px → 120px
   - Увеличены внутренние отступы (padding) во всех карточках

4. **Улучшенное распределение пространства**
   - Блоки используют `flex: 1` для заполнения доступного пространства
   - Контент центрируется вертикально с помощью `justify-content: center`
   - Добавлено `justify-content: space-between` для равномерного распределения

## Структура блоков

```
┌─────────────────────────────────────────────────────────┐
│  [Следующая тренировка]  [Последняя]  [Добавить]  [|||] │
│  [Цель по весу]          [тренировка] [Журнал]    [|||] │
│                                                     [|||] │
└─────────────────────────────────────────────────────────┘
```

Все блоки теперь:
- Выровнены по верхней линии
- Имеют одинаковую высоту в своих рядах
- Занимают больше места на экране
- Лучше используют доступное пространство

## Адаптивность

- На экранах < 1200px: ширина колонок 340px
- На экранах < 1024px: блоки занимают 100% ширины
- Сохранена полная адаптивность для мобильных устройств
