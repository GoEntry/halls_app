# Обновление приложения HALLS - Роутинг и расширенный функционал

## Что было реализовано

### 1. Полноценный роутинг вместо модальных окон

Заменили все модальные окна на отдельные страницы с собственными URL:

**Маршруты:**
- `/` - Главная страница (дашборд)
- `/trainings` - Журнал тренировок
- `/trainings/new` - Добавление новой тренировки
- `/trainings/:id` - Редактирование тренировки
- `/nutrition` - Журнал питания
- `/videos` - Видео-тренировки
- `/goals` - Цели и прогресс
- `/profile` - Профиль пользователя

### 2. Навигационный header

Создан компонент `AppHeader` с навигацией по всем разделам:
- Sticky позиционирование
- Активное состояние для текущей страницы
- Адаптивный дизайн для мобильных устройств

### 3. Новые страницы и функционал

#### Журнал тренировок (`/trainings`)
- Список всех тренировок с карточками
- Фильтрация по типу тренировки
- Поиск по названию
- Статистика: общее количество, дистанция, калории
- Удаление тренировок
- Переход к редактированию

#### Форма тренировки (`/trainings/new`, `/trainings/:id`)
- Добавление новой тренировки
- Редактирование существующей
- Выбор типа из списка
- Автоматический расчет калорий
- Поля: тип, дата, длительность, дистанция, пульс, заметки

#### Журнал питания (`/nutrition`)
- Отслеживание приемов пищи
- Дневная статистика калорий и макронутриентов
- Прогресс-бар достижения дневной цели
- Добавление приемов пищи с полной информацией
- Готовые планы питания (2000, 3000, 4000 ккал)

#### Видео-тренировки (`/videos`)
- Каталог видео с YouTube
- Фильтрация по категориям: Все, Домашние, Кардио, Силовые, Йога, HIIT
- Карточки с превью, длительностью, уровнем сложности
- 8 готовых видео-тренировок

#### Цели и прогресс (`/goals`)
- Создание персональных целей
- Отслеживание прогресса с визуальным индикатором
- Статусы: В процессе, Достигнута, Просрочена, Срочная
- Обновление текущего значения
- История достигнутых целей
- Единицы измерения: кг, км, раз, мин, ккал

#### Профиль пользователя (`/profile`)
- Личная информация: имя, email, телефон, дата рождения, пол
- Физические параметры: рост, вес
- Автоматический расчет ИМТ (индекс массы тела)
- Цели и предпочтения: основная цель, уровень активности
- Выбор предпочитаемых видов тренировок
- Статистика: всего тренировок, дней с нами, сожжено калорий, активных целей

### 4. Улучшения UX

- Плавная прокрутка при переходе между страницами
- Единый стиль для всех страниц
- Адаптивный дизайн для всех разрешений
- Интерактивные элементы с hover-эффектами
- Подтверждения при удалении данных

### 5. Хранение данных

Все данные сохраняются в localStorage через композабл `useLocalStorage`:
- `trainingLog` - журнал тренировок
- `meals` - приемы пищи
- `goals` - цели пользователя
- `userProfile` - профиль пользователя
- `weightGoal` - цель по весу
