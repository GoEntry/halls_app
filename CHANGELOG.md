# Changelog - HALLS Application

## [2.0.0] - 2026-04-04

### Крупное обновление: Полноценный роутинг и расширенный функционал

#### Добавлено
- **Роутинг:** Заменены все модальные окна на отдельные страницы с URL
- **Навигация:** Добавлен sticky header с навигацией по всем разделам
- **Страница тренировок:** Полноценный журнал с фильтрацией и поиском
- **Форма тренировки:** Добавление и редактирование с автоматическим расчетом калорий
- **Журнал питания:** Отслеживание приемов пищи и макронутриентов
- **Видео-тренировки:** Каталог из 8 видео с категориями
- **Цели и прогресс:** Система отслеживания персональных целей
- **Профиль пользователя:** Полная информация, ИМТ, статистика

#### Изменено
- Переписан роутер с 1 маршрута на 8 маршрутов
- Обновлен App.vue с интеграцией header
- Улучшена структура компонентов
- Оптимизирован размер bundle (CSS: 62.96 kB, JS: 146.74 kB)

#### Технические улучшения
- Добавлен scrollBehavior в роутер
- Все данные сохраняются в localStorage
- Полная адаптивность для всех устройств
- Единый стиль для всех страниц

## [1.0.0] - 2026-04-03

### Рефакторинг и оптимизация

#### Добавлено
- Модульная архитектура компонентов
- Композабл useLocalStorage
- Базовые UI компоненты (BaseModal, DashboardCard)
- Компоненты карточек дашборда
- Модальные окна для всех действий

#### Изменено
- Переписан с Options API на Composition API
- Разбит монолитный Halls.vue (389 строк) на 15+ компонентов
- Оптимизированы стили (650 строк → 200 строк)
- Исправлено подключение шрифтов
- Улучшено центрирование и размеры блоков

#### Удалено
- Неиспользуемые файлы (views, icons, tests)
- Дублирующиеся SCSS файлы
- Старые компоненты
